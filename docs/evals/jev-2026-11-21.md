# Jev decision requests through OpenRouter, 2026-11-21

Four real Nexus decision requests exercised two contrasting text tickets and
two contrasting PNGs. The client created each request through the workspace
Agent API, received HTTP 202, ran admission and execution, and retrieved its
completed typed answers and settled USD cost through the read endpoint.

The two image requests had identical instructions and questions. Only the
encoded pixels changed. Jev gave the correct color confidence 1.0 in both.
A separate pair of 128 × 128 PNGs sent with the Nexus adapter returned HTTP 400
for invalid image dimensions. OpenRouter documents PNG and JPEG input and a
minimum image area of 78,400 pixels. Only PNG was exercised here.
[OpenRouter multimodal decisions](https://openrouter.ai/docs/guides/community/multimodal-decisions)

Nexus resolves `openrouter/jev-latest` to `~typesafe/jev-latest` and posts
to `/api/v1/systemone`. The adapter maps the evidence to `state` and the
questions to a map keyed by name. TypeSafe's `noul` becomes a predicate
probability in the result. Independent adapter calls returned HTTP 200 and
identified the serving model as `typesafe/jev-1.14-20261014`. A separate
text call to OpenRouter's `/api/alpha/decisions` returned HTTP 200 with the
same serving model, billing probability 0.98 and choice `billing`. The
existing System One route supports these cases. [OpenRouter System One API](https://openrouter.ai/docs/api/api-reference/systemone/submit-a-system-one-request)

The first-party Python SDK packages image assets as multipart file parts.
OpenRouter accepted the PNGs as JSON `image_url` parts inside `state` on
the System One route. These calls exercised Nexus's OpenRouter credential
and transport. The native TypeSafe service was outside this run.

At verification time, OpenRouter advertised text and image input, decisions
output, and 262,144 tokens of context. The reported charges matched $0.042 per
million input tokens and zero output charge on all four Nexus requests.
The alias follows the latest Jev release and its price can change.
