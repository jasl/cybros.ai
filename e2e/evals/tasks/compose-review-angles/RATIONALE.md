# compose-review-angles

**Measures.** The compose ceiling objective (O1) THROUGH `exe/rho`: three
reviews of one patch at once, each a fresh model member that opens
`patch.diff` itself, and one verdict step that reads all three — the fan
and merge no list of plain calls can spell. The script the model wrote is
read off the compose row's `tool_input.script`; its picture is scored on
the plan the kernel placed for it (`ComposeBench::Executed`), the script's
text reading riding beside it under `static` and still the only word on
whether the script built; beside those the kernel's own verdict: the
branch under the call completed.

**Converts.** `e2e/support/compose_bench/objectives.rb:21` (O1, its
hand-written `Picture`); the door is the gallery's `plain` driver with the
compose switch on (`flags.compose`). The fixture is a real `patch.diff`
with a security, a performance and a style problem, so the three angles
have something to find.

**Dimensions.** reach = a `compose` row (an aliased `Workflow` call resolves
to the same wire name on the row); success = `valid_first` (the script's
text) AND O1's exact edges and reads on the plan the kernel placed AND
every node under the call completed; the score's columns (`silent` buckets,
the lowered graph, the `static` text reading) are facts. No
verification: the verdict is prose. On the floor tier success is usable
generation instead (`Predicates.compose_usable`): a compose call of the run
settled without an error, placed a node, every stage source parses, and a
placed node is not a stage that failed on its own script; the picture rides
as the `picture` fact on both tiers, `usable_on_call` (the first call that
met the bar) beside it.

## Reading a red

- **lane bug** — `error` on the record (`rho do` refused, the graph read
  failed) or `stopped: deadline` with `rounds_settled: 0`.
- **model conduct** — "no compose call: the model called {bash: 3}" (it
  reviewed the patch itself, or fanned `task` calls); "the script was
  refused script_error: …" (invalid first); "the picture is not the
  objective's (silent: over_sync)" — the dataflow buckets name what it
  wired wrong; "(silent: reads_mismatch)" is a verdict that names fewer
  than the three reviews, or none — a step reads only what it names, so a
  verdict naming nothing reads its prompt alone. A record on the floor; a
  re-cut of the compose text only when the strong tier shows the same
  bucket.
- **kernel finding** — the script scored exact and the branch did NOT
  complete ("r1t0-model-4(failed) did not complete under r1t0"): the
  kernel's run of a right script is the finding; a round `failed` with a
  kernel error key; an `attention_required` nobody scripted; `kernel_check`
  not true — a composed step handed something it did not name.
- **on the floor** — the predicate is usable generation by a compose call
  of the run, never the picture. Its red — no call met the bar — is model
  conduct and names the first call's failure, one of: the kernel refused
  the call (the script's own error), it placed nothing, a stage does not
  parse, or nothing it placed stands (the stages that did its work failed
  on their own scripts); a call that did not complete names its error key,
  read as the kernel-finding bullet says. `usable_on_call` records the
  first call that met the bar — above 1, the first call missed and a
  recovery later in the run met it — and the `picture` fact carries the
  strong tier's reading with its buckets — a `task_pass` apart from the
  predicate is read against those two, never as a picture the scorer
  called wrong.
