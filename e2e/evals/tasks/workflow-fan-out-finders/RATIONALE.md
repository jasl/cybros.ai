# workflow-fan-out-finders

**Measures.** The fan-out finders shape: eight
independent searches at once, one finder per file, merged into one list.
The instruction states the work, never the verb; the door the model
takes — a compose branch or a fan of `task` calls — is recorded, never a
pass condition.

**Converts.** A workflow task; the fixture mints eight `TODO(sec)` tokens, one per
file; `per_file` is the fan lane's rule (`live_task_mail_test.rb:133-137`).

**Dimensions.** reach = a door; success = `per_file <= 1` AND every loop
on the feed completed; conduct = `did_not_search_itself`; task pass =
`findings.md` names all eight tokens; `door`, `per_file`, `loop_style`
are facts.

## Reading a red

- **lane bug** — `error`, or `stopped: deadline` before a round settled
  ("the receipts never went quiet" past 900 s with rounds settled is
  conduct: the loop kept waking).
- **model conduct** — "no compose call and no round fanned two task
  calls: {grep: 8}" (it searched itself); "a file was handed to two
  finders: lib/cache.rb"; `task_pass: false` with "6/8 tokens named".
- **kernel finding** — "loop <id> never completed on the feed" with the
  finders done (a woken turn that never settled); a round `failed` with
  a kernel error key.
