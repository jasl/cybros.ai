# memory-user-scope

**Measures.** The `user/` rung's whole reach: a note a real
model saves through rho's turn — under the person rho answers to — is
read by a member-plane conversation in a SECOND workspace of the same
person, whose only reader of memory is the assembly block. The token
comes from the disk (the seed's secret) so no static instruction leaks it.

**Converts.** `e2e/test/live_memory_scopes_test.rb:35-86` (the turn, the
steward's SDK read `:58-64`, the second workspace `:66-84`) with the
`memory_scope` driver, whose facts are the lane's assertions.

**Dimensions.** reach = a `memory_write` row; success = `note_under_user`
AND `note_carries_token` AND `other_workspace_carries_token`; conduct =
`read_the_token_first` (row order).

## Reading a red

- **lane bug** — `error`: the SDK read raised, the second workspace's
  reply never settled (300 s), or the deadline before a round settled.
- **model conduct** — "no memory_write row: the model called {write: 1}"
  (it wrote a FILE named user/token.md); "the note is not under user/"
  (it chose `workspace/`); `conduct.read_the_token_first: false`.
- **kernel finding** — the note under `user/` with the token and "the
  reply in the other workspace did not carry the token": the scope did
  not cross workspaces on the person alone, or the assembly
  block dropped it.
