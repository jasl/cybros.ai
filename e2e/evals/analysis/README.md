# Historical evaluation conclusions

These dated Markdown readouts record the conditions, results and qualifications
of particular investigations. Model names and measured quantities describe those
historical runs; they do not select current product models or gate regression
tests.

Raw records, generated tables, logs, stamps, dry runs, report assembly fragments
and one-off analysis scripts are local artifacts under
`e2e/artifacts/evals/analysis/`, with run records under
`e2e/artifacts/evals/runs/`. They are not distributed with the source. References
in a historical readout to its original script, trace or run path may therefore
require the locally retained material.

New automated evaluations write ignored artifacts. Save a concise, reviewed
conclusion here only when it is useful beyond that run. Reusable task definitions,
generators and synthetic regression inputs belong to the ordinary evaluation
and test trees, independently of the measured provider or model.
